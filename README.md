# RePlate MVP

Web-first RePlate MVP for a Nagpur pilot. This version is optimized for student-friendly development and founder-led operations.

## What is included

- Role-based dashboards for restaurant, consumer, NGO, and admin
- Listing creation and discovery
- Reservation flow with auto-expiry
- Admin verification and pilot metrics
- Seed data for a Nagpur demo

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
